# 考古題刷題網站（通用版提示詞）

請用我附上的 **template.html**（刷題網站「網頁提示詞」裡按「下載網站模板」取得）加上我的講義與考古題，做出同一套刷題網站，只是換成我的科目。全程台灣繁體中文。請在可以執行程式、上傳檔案的環境使用。

**做法：模板已經包含全部功能與版面，不要重寫或修改模板程式。** 你只要寫兩個檔案：
- `data.json`：這一科的題目與設定，格式照最下方「data.json 規範」。
- `theme.css`：配色風格，只放 CSS 變數。

再用程式把這兩個檔案填進模板，輸出成單一 HTML 網站。

## 開始前一次問完

2. **資料**：請我上傳今年講義、課程大綱（有的話）、考古題，並問考古題有沒有參考答案；有共筆詳解、教科書節錄或老師補充檔也一起附上。我附的每一份都是有效來源，答案與詳解的依據以今年講義為優先、其他資料補充，每一處都要寫清楚依據哪一份；我也可能在對話裡直接口述補充。沒有 template.html 或沒有教材，就先跟我要，不要自己編題目。
3. **風格**：請我用文字描述想要的感覺，例如「簡潔清爽」「柔和粉彩」「沉穩專業」，或給顏色碼、參考網站。先整理成配色摘要（主色、強調色、背景、主要按鈕色、深色模式）給我確認再開工。
4. **標題區**：學校、系級、學期、作者署名；不想寫的留空，網站上就不顯示那一項。
5. **版本號**：沒指定就用 v1.0。

我說「開始製作」前，只確認收到哪些檔案、各歸哪一類。

## 題庫規則
1. 只收考古題（與講義內附的國考題）。不自己出題，也不收講義自編題。
2. 範圍依今年講義實際內容判斷；題目與選項對不上、原卷缺頁的題目排除。每一份考卷都要逐題過一遍：往年期中卷裡考點屬這次期末範圍的題目也要收，反之亦然。
3. 每份考卷列出收錄情形：原卷題數、收錄題數、排除題號與原因（寫進 `papers.raw`、`excluded`）。
4. 題目依內容歸單元，單元代號用講義章節 L01、L02…。
5. 重複題合併成一題並列出所有出處；改寫成情境題或選項換順序，但考點與正解相同的也合併；問法相反（屬於／不屬於）算新題。
6. 答案依參考答案並對照詳解；和講義矛盾時依講義，`n` 以「⚠️」開頭說明。沒有參考答案的標「依講義判斷」。
7. 題目標明「複選」或「多選」才做成多選（`m:1`，題幹結尾標「（多選）」）；沒標明但有多個正解的，選到任一個就算對。
8. 題目 `id` 等於第一個出處，之後不能改；新出處只能加在 `src` 後面。
9. **題幹與選項完全照原卷原文，不論原文是什麼語言**：全英文維持全英文，全中文維持全中文，中英混雜就照原樣；不改寫、不翻譯、不補中英對照、不統一格式、不修潤用字，標點與大小寫都照原卷（缺漏的處理見第 10 條）。非選題的題幹同一條規則。**只有詳解、核心觀念、觀念卡與非選題的參考答案**裡的專有名詞寫成「英文(中文)」，例：Levodopa(左旋多巴)。
10. **缺漏自補**：原卷題幹或選項有缺字、印刷不清、漏印選項時，先用同一題的其他卷別補，沒有再依今年講義或參考答案補；補上的文字用〔 〕括起來，其餘照原文，`n` 寫明補了什麼、依據哪份資料的第幾頁。補不出可靠內容的題目不收，寫進 `excluded`。補過的題號都要在回報列出來讓我對照原卷。這是除了合併題之外，唯一可以動原卷文字的情況。
11. 題目有附圖（例如「如下圖，哪一個是…」）時，**直接取出原卷裡的原始圖檔**放進該題的 `img`，畫質最好也不會截歪：docx 用 `pandoc --extract-media` 抽文字，圖會出現在題目原本的位置；PDF 先用 PyMuPDF 取出內嵌圖檔，依圖在頁面上的位置對到題號（每頁都出現的背景、校徽略過）。圖上另外疊了標號、文字框或箭頭時，原始圖檔裡沒有這些，改用 PyMuPDF 依那張圖在頁面上的位置、以原圖的解析度把那一區連同標註一起渲染出來（位置取自 PDF 本身，不會截歪）；圖不是獨立圖檔（掃描整頁、向量繪圖、被切成很多小塊）時也這樣渲染裁切。逐張看過確認對到正確題目，壓成寬 600px 以內的 JPEG，以 data URI 放進 `img`；真的取不到圖才排除，回報時請我對照原卷。**選項本身是圖**（例如「下列哪一張是…」）時，把各選項的圖照原卷順序排成一張（2×2 或一排），每張圖旁標上大字 A、B、C、D，合成一張圖放進 `img`（題幹本來也有圖就放在它後面），`o` 寫成 `["見圖 A","見圖 B",…]`，逐選項詳解先講那張圖是什麼再解釋對錯，`n` 註明選項原為圖片。

## 題型判斷
抽完考卷文字後，**自己逐題判斷是選擇題還是非選題，不要問我**：
- 原卷的分段標題最準（「一、單選題」「三、非選題」「問答題」「填充題」），標題下的題目照那一段的題型。
- 題幹後面有 (A)(B)(C)(D)、A. B. C. D.、①②③④ 之類的並列選項 → 選擇題。
- 沒有選項、題幹是「試述／說明／比較／列舉／何謂／請寫出／名詞解釋」或帶配分要寫文字 → 非選題。
- 參考答案是單一字母 → 選擇題；是一段文字或分點 → 非選題。
- 是非題當選擇題（選項照原卷用字）；填充題當非選題（一格一個要點）；配對題當選擇題（名單當選項，每小題一題）；原卷標多選的用 `m:1`。
- 一題裡又有選擇又有問答就拆成兩題，題號加 a／b，並在 `n` 說明來自同一題。
- 判不出來的預設做成非選題，不要自己生選項，最後回報時列出來讓我對照原卷。

## 非選題（簡答／問答）
考卷有非選題（簡答、問答、試述…）時也要收，和選擇題放在同一個 `qs` 陣列，用 `w:1` 標記。非選題在網頁上是**單字卡**：看題幹 →自己答 →按「看參考答案」→自評「我答得出來／部分答對／答不出來」，自評結果和選擇題共用同一個錯題本與記憶曲線（部分答對和答不出來都算答錯）。

非選題的欄位：`w:1`、`ans`（參考答案要點陣列，照得分點拆，一點一句，必填）、`kw`（關鍵字，可省）、`e`（整體詳解，一段一個字串，可省；不是逐選項詳解）、`ansImg`（參考答案的示意圖，翻卡後才顯示，可省；題目要看的圖放 `img`，答案圖放 `ansImg`，不要放錯讓人翻卡前就看到答案），**不要給 `o`、`a`、`m`**。出處題號用 E 開頭（例 `11401M-E1`），網頁會顯示成「非選第 1 題」。

`ans` 要寫成自己對照得分的樣子：每一點是完整句子，看了就知道自己有沒有寫到，不要只寫一個名詞。

## 組裝
`site.storageKey` 與 `site.dbDoc` 取一個這個網站專用的名字（英數小寫加連字號），發布後永遠不要改，否則大家的作答紀錄會接不上。寫好之後用這段程式組成網站：

```python
import json,re
t=open('template.html',encoding='utf-8').read()
D=json.load(open('data.json',encoding='utf-8'))
data=json.dumps(D,ensure_ascii=False,separators=(',',':')).replace('<','\\u003c')
theme=open('theme.css',encoding='utf-8').read()
def put(pat,new):
    global t; t,n=re.subn(pat,lambda m:new,t,count=1,flags=re.S); assert n==1,pat
put(r'(?<=<script id="site-data" type="application/json">).*?(?=</script>)',data)
put(r'(?<=<style id="theme">).*?(?=</style>)','\n'+theme+'\n')
put(r'(?<=<title>).*?(?=</title>)',D['site']['title'])
open('index.html','w',encoding='utf-8').write(t)
```

## data.json 規範（exam-quiz-site/1）

網站＝模板（固定程式）＋ data.json（這一科的內容）＋ theme.css（風格）。只寫 data.json 與 theme.css，不改模板。所有文字用台灣繁體中文；`info`、`coverageExtra.note`、`coverageNote` 可含簡單 HTML，其餘一律純文字。

用工具組 build 時，`build.py` 會先跑 `scripts/validate.py` 檢查這份規範：❌ 錯誤（網站會壞掉或違反規範）就不輸出網站；⚠️ 提醒（例如相同的選項文字、正解詳解沒以「正確：」開頭）照樣輸出，確認是故意的就可以留著。

### 最上層
```json
{
 "schema": "exam-quiz-site/1",
 "site": {...}, "info": [...], "answerSources": {...}, "exams": [...],
 "units": [...], "lectures": [...], "yearGroups": [...], "yearLabels": {...},
 "papers": {...}, "excluded": {...}, "alias": {}, "coverageExtra": [...], "coverageNote": "",
 "qs": [...], "topics": {...}
}
```
**必填**：`site`、`units`、`exams`、`yearGroups`、`yearLabels`、`papers`、`answerSources`、`qs`。其餘可省略（省略時當成空的）。

### site（網站設定）
| 欄位 | 說明 |
|---|---|
| title | **必填**。網頁名稱（瀏覽器分頁與 Artifact 標題），例 `學校科目期中刷題_學期_作者_v1.0` |
| h1 / h1em | h1 **必填**，h1em 可省。大標，h1em 會用強調色顯示，例 `"病理學期中"`、`"刷題"` |
| version | **必填**。例 `v1.0`，顯示在大標後的小字；改版時與 title 一起改 |
| band | **必填**，最多兩段文字的陣列。標籤帶左右兩段文字：`["學校・科目・系級・學期・by 作者", "期中範圍 L01–L07"]`，空著的項目省略 |
| deco | 可省（＝none）。大標右側裝飾：`"pill"`（膠囊）／`"tissue"`（玻片圓）／`"none"` |
| storageKey | **必填**。瀏覽器存檔前綴，英數小寫加連字號，例 `school-patho-mid`。**發布後永遠不可改**，否則使用者進度會不見 |
| dbDoc | **必填**。帳號存檔名稱，例 `progress-mid`。**發布後永遠不可改** |

### info（「網頁說明」段落）
`[{"h":"收錄範圍","t":"…共 {total} 題…"}, {"h":"答案來源","t":"…"}, {"h":"功能","t":"…"}]`；`{total}` 會換成題數。

### answerSources（答案來源標籤）
每題的 `as` 指向這裡。每個來源都要有 `label`；`cls`：`ok` 綠、`multi` 黃、`chk` 灰（可省，＝chk）。
```json
{"official":{"label":"已對照參考答案","cls":"ok"},"lecture":{"label":"依講義判斷","cls":"chk"}}
```

### exams（考試倒數）
`[{"key":"mid","name":"期中考","date":"2026-11-18","units":[1,2,3]}]`。**至少要有一次考試**（倒數與記憶曲線靠它）；`key` 不可重複，`date` 寫成 `YYYY-MM-DD`。units 是這次考試包含的單元 id；只有一次考試可省略 units（＝全部單元）。
有兩次以上考試都寫了 units 時（例：期中＋期末的全範圍網站），首頁「選擇範圍」卡會多一排「考試範圍」按鈕（按鈕文字＝name），點一下就改選那次考試的全部單元。期中期末都有教的單元，兩次考試的 units 都要列（例：腹部 `[...,5]` 同時出現在期中與期末）；記憶曲線排程以陣列中最後一次列到它的考試為準，所以 exams 依考試日期由早到晚排。

### units（單元）
`[{"id":1,"code":"L01","name":"細胞損傷","sub":"9/10・講義全名・老師"}]`。id 為整數（不是字串 `"1"`）、不可重複、排序依陣列順序；code、name 必填，code 用講義章節代號；sub 是單元卡上的說明小字，可省。

### lectures
「上課講義對照章節」每行一筆：`"L01_講義章節全名_9/10"`。

### 年份與考卷
- `yearLabels`：年份 key → 按鈕文字，例 `{"1141":"1141 牙醫","M1141":"1141中 牙醫","N1141":"1141 國考"}`。
- `yearGroups`：年份按鈕分組與順序，每組要有 `label` 與 `years`，例 `[{"label":"期中卷","years":["1141","1132"]},{"label":"國考","years":["N1141"]}]`；每個年份只能出現在一組。
- `papers`：考卷代碼 → `{"year":"1141","raw":50,"suffix":""}`。代碼就是出處 `src` 的 `-` 前面那段（例 `11401M`）；代碼**不能含 `-`**；`year` 必填，要是 `yearLabels` 裡的 key；`raw` 是原卷題數（整數，不知道就填 null 或省略），有填的才會列在「各份考卷收錄情形」表格；`suffix` 接在出處名稱後（例國考填 `"牙醫學（二）"`）。
- `excluded`：沒收錄的題目 `{"11401M-36":"題幹與選項不符"}`，會列在收錄情形。
- `coverageExtra`：收錄情形表格的額外列（`name`、`prefix` 必填），算的是年份 key 以 `prefix` 開頭的題目：`{"name":"國考","prefix":"N","papers":"10 份","note":"…{units}…"}`；`papers` 留 null 會自動算份數，`{units}` 換成涉及的單元代號，`{n}` 換成題數。
- `coverageNote`：表格下方的說明。
- `alias`：題目 id 改名時 `{"舊id":"新id"}`，讓舊紀錄接上；平常留 `{}`。

### qs（題目）
```json
{"id":"11401M-9","u":1,"ys":["1141","1132"],"src":["11401M-9","11302M-8"],
 "q":"題幹（照原卷原文）","o":["選項A","選項B","選項C","選項D"],"a":["A"],
 "e":["正確：…（引講義細節）","…為什麼錯","…","…"],"m":0,
 "k":{"白":"白話說明","專":"專業術語版","錯":"易錯點"},"t":["topicKey"],"n":"附註","as":"lecture"}
```
| 欄位 | 說明 |
|---|---|
| id | ＝第一個出處 `src[0]`，是作答紀錄的 key，**發布後不可改** |
| u | 單元 id（要在 units 裡） |
| ys | 出現過的年份 key，非空陣列，每個都要在 yearGroups 裡（選年份時只要其中一年被選就會出題） |
| src | 所有出處，非空陣列，格式「考卷代碼-題號」（剛好一個 `-`，代碼要在 papers 裡）；新出處只能加在後面 |
| q / o | 題幹與選項，照原卷原文，不改寫、不翻譯；2–5 個選項 |
| a | 正解字母陣列 |
| m | 1＝多選題（題幹結尾標「（多選）」，全選對才算對）；0＝單選。`m` 為 0 但 `a` 有多個時，選到任一正解即算對 |
| e | 逐選項詳解，數量＝選項數；正解以「正確：」開頭（沒有會出 ⚠️ 提醒）；專有名詞寫成「英文(中文)」 |
| k | 可省。核心觀念物件，只認三個 key：白（白話）、專（專業術語）、錯（易錯） |
| t | 可省。相關觀念卡 key 陣列，每個都要在 topics 裡 |
| n | 可省。附註文字；以「⚠️」開頭會加上「依講義改答」標籤 |
| as | 答案來源，對應 answerSources |
| w | `1`＝非選題（見下一節）；選擇題不給這個欄位。`ans`、`kw`、`ansImg` 只能用在非選題 |
| img | 題目附圖（可省）：data URI 字串陣列（`data:image/jpeg;base64,…`），顯示在題幹下方；網站是單一檔案，圖片要內嵌，建議先壓成寬 600px 以內的 JPEG。圖要優先取原卷的原始圖檔（docx 的 word/media、PDF 的內嵌圖），不是獨立圖檔時才截圖裁切。選項本身是圖的題目，把選項圖照原卷順序合成一張（每張標上大字 A、B、C、D）放進 img，`o` 寫 `["見圖 A","見圖 B",…]`。選項是圖上標號（1、2、3…）的看圖題用它放原卷的圖 |

### 非選題（簡答／問答，做成單字卡）
同一個 `qs` 陣列裡用 `w:1` 標記；沒有選項與正解，改成「翻卡自評」。
```json
{"id":"11401M-E1","u":1,"w":1,"ys":["1141"],"src":["11401M-E1"],
 "q":"試述…（10 分）（照原卷原文）",
 "ans":["要點一（完整句子，看得懂就能對照）","要點二","要點三"],
 "kw":["necrosis","apoptosis"],
 "e":["整體詳解段落一","段落二"],
 "k":{"白":"…","專":"…","錯":"…"},"t":[],"n":"","as":"official"}
```
| 欄位 | 說明 |
|---|---|
| w | `1`＝非選題。不給就是選擇題 |
| ans | **必填**，參考答案的要點陣列，照得分點拆開，一點一句；網頁會編號列出 |
| kw | 關鍵字（可省）。未翻卡前有「看關鍵字提示」按鈕，翻卡後列在參考答案下面 |
| e | 整體詳解（可省）。**數量不必等於任何東西**，一段一個字串；不是逐選項詳解 |
| ansImg | 參考答案附圖（可省）：data URI 字串陣列，翻卡後顯示在參考答案下面，**翻卡前看不到**。用來放參考答案的示意圖（例如窩洞修形圖、作圖題的解答圖）；題目本身要看的圖放 `img`，不要把答案圖放進 `img` 以免翻卡前就看到答案 |
| o / a / m | **不可給**（連空陣列、`m:0` 都不要寫）。非選題沒有選項、沒有正解字母，也不能標多選 |
| 其他 | `id`、`u`、`ys`、`src`、`k`、`t`、`n`、`as` 和選擇題完全一樣 |

出處題號用 **`E` 開頭**（`11401M-E1`），網頁會顯示成「1141 牙醫 非選第 1 題」；`id` 仍然等於 `src[0]`，發布後不可改。

作答方式：看題幹 → 自己答 →「看參考答案」→ 自評「我答得出來／部分答對／答不出來」。自評寫進和選擇題同一份作答紀錄，所以錯題本、收藏本、記憶曲線、錯題輸出、進度統計全部共用：**「部分答對」與「答不出來」都算答錯**，會進錯題本、隔天再出現。

首頁「選擇範圍」卡下面會自動出現「題型：全部／只選擇題／只非選題」。**資料裡沒有任何 `w:1` 的題目時，這排不會出現**，舊科目的網站外觀完全不變。

### topics（觀念卡）
`{"key":{"t":"卡片標題","s":"L03 單元名","k":["一次看懂的知識點",…],"c":["易混淆點",…]}}`；四個欄位都要有，`k`、`c` 是陣列。

### theme.css（風格）
只放 CSS 變數，模板不用改。淺色寫在 `:root{}`，深色寫兩次：`@media (prefers-color-scheme: dark){:root:not([data-theme="light"]){…}}` 與 `:root[data-theme="dark"]{…}`。
| 變數 | 用途 |
|---|---|
| --bg、--grid | 頁面底色、背景格線 |
| --surface、--surface2、--line | 卡片底、次要底、框線 |
| --ink、--muted | 主文字、次要文字 |
| --hema、--hema-soft | 主色（主要按鈕、選取） |
| --eosin、--eosin-soft | 第二強調色（題號、觀念） |
| --label、--label-ink、--label-soft | 標籤帶、輸出按鈕與倒數方塊的強調色 |
| --good/-soft、--bad/-soft、--warn/-soft | 答對、答錯、提醒 |
| --hand、--body、--mono | 標題字、內文字、數字字型 |
| --r | 卡片圓角 |
