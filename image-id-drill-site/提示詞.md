【內容】
1. 一張圖一題，答案是名稱；器械、標本附功能與特徵，玻片附看片重點，每張都標講義頁碼。
2. 正常對照圖、答不出名稱的圖不出題，並告訴我為什麼沒收。
3. 必考只收資料或我明寫、明說的：我附的每一份資料都可以有標記（講義或共筆的文字標記、講義上的螢光筆與手寫註記、老師上課說的、我在對話裡口述指定的），引用原文並註明是哪一份資料的第幾頁，我口述的寫「使用者指定」（寫進 must）；不要把你自己判斷的重點標成必考，也要提醒沒標到的一樣可能考。圖片優先用今年講義的，講義沒有才用其他資料。
4. 講義原圖上的文字標註與箭頭會洩答案：練習用的圖要遮掉（img），原圖另存（orig），答完與圖譜顯示原圖。抽幾張檢查沒有遮到組織。
   - 取圖時**能用原始圖檔就用原始圖檔**（PDF 用 PyMuPDF 取內嵌圖、docx 用 `pandoc --extract-media`），畫質最好也不會截歪；每頁都出現的背景、校徽略過。標註是另外疊在圖上的文字框、箭頭時，原始圖檔本身就沒有標註，直接當練習用的圖（img），不必遮；原圖（orig）用 PyMuPDF 依圖在頁面上的位置、以原圖解析度連同標註一起渲染出來。標註燒在圖裡、掃描檔、向量繪圖或好幾塊拼成的圖，才渲染裁切再照上面的方法遮。
5. 選擇題 4 選 1，正解位置分散；每個選項都寫詳解（正解寫「正確：」加圖上看得到的特徵與頁碼，其他寫和這張圖的差別）。
   - 自編的題目：干擾選項取**同一章、而且盡量同一節或同一個器官／部位**的相關項目（腎臟的題目就配腎臟腫瘤，攝護腺的題目就配攝護腺病灶），不要跨部位亂配；同章同部位湊不到三個時，可以用教材提過但沒做成題目的名稱當干擾選項。
   - 自編題目的**題幹專有名詞也只寫英文**：題幹其餘用中文（例「這張圖的診斷為何？」「白色箭頭所指的構造是？」），但器官、構造、病名、器械名一律寫英文、不加中文。
   - 自編題目的**選項只寫英文專有名詞**，不要加中文；中文譯名放到答完後的逐選項詳解，寫成「英文(中文)」。這樣比較接近真正的考卷。
   - **考古題、老師洩題、國考題例外**：題幹與四個選項完全照原樣，原本是中英夾雜或全中文就保持原樣，不改語言、不加也不刪中文、不調順序。
6. 自編的題目、干擾選項與翻譯要標明沒有老師審閱；超出教材的說明列出來讓我對照課本。

【組裝】
site.storageKey 與 site.dbDoc 取這個網站專用的名字，發布後永遠不要改。features 照我選的「要做哪些」與「作答模式」設定。寫好後用這段程式組成網站：

```python
import json,re
t=open('template.html',encoding='utf-8').read()
D=json.load(open('data.json',encoding='utf-8'))
data=json.dumps(D,ensure_ascii=False,separators=(',',':')).replace('</','<\\/').replace('<!--','\\u003c!--').replace('<script','\\u003cscript')
theme=open('theme.css',encoding='utf-8').read()
def put(pat,new):
    global t; t,n=re.subn(pat,lambda m:new,t,count=1,flags=re.S); assert n==1,pat
put(r'(?<=<script id="site-data" type="application/json">).*?(?=</script>)',data)
put(r'(?<=<style id="theme">).*?(?=</style>)','\n'+theme+'\n')
put(r'(?<=<title>).*?(?=</title>)',D['site']['pageTitle'])
open('index.html','w',encoding='utf-8').write(t)
```

發布時把 index.html 和 fig/ 一起放上去（在 Claude 發布時，要開啟儲存進度的 db、user，以及「下載網站模板」「下載離線版」用的 downloads 權限）。首頁的「下載離線版」會把網站和 dims 列到的全部圖片打包成一個 HTML 檔，斷網也能用，模板已內建，不用另外做，所以每張用到的圖都要列在 dims。首頁的「進度備份」可以把作答紀錄、收藏與考試日期下載成一個 .json 檔，上傳時選「合併」或「取代」（可復原，別的網站的進度檔會被拒收），用來換裝置或在線上版與離線版之間搬進度，同樣是模板內建、用同一個 downloads 權限，不用另外做。要 A4 PDF 時另外做一份列印版：每個編號盡量同一頁、圖多的一排三張、沒有跨頁與空白頁。

【完成前檢查】用程式檢查 data.json（代號不重複、每個項目都在某一章、選擇題答案在選項內且詳解數等於選項數、所有圖片都有寬高）。用手機與電腦尺寸實際點過圖譜、每一種作答模式、「只出必考」篩選、錯題本與收藏本的表格（全選、單勾、排序、輸出、下載 PDF、練習勾選、取消收藏與復原）、總檢討的「這輪錯題 PDF」（下載 PDF 是自我測驗排版，下載前選「考卷＋解答分開」或「題目與答案同頁（答案在虛線下方）」，兩種都要試）、輸出與倒數、進度備份的下載與上傳（合併、取代、復原），確認都有反應、圖片載得出來、沒有錯誤訊息、沒有左右捲動。完成後告訴我：總圖數、題數、必考數、沒收的圖與原因、哪些是自編內容，以及測試過與沒測到的部分。之後要修改時只改 data.json、theme.css 或圖片再重新組裝，並先問我新的版本號。

## data.json 規範（image-id-drill-site/1）

網站＝模板（固定程式與版面）＋ data.json（這一科的內容與設定）＋ theme.css（風格）＋ fig/ 資料夾（圖片，檔名＝圖片代號.jpg）。只寫 data.json、theme.css 與圖片，不改模板。全站台灣繁體中文，英文專有名詞寫成「英文(中文)」。

文字裡用 `==關鍵字==` 標出遮重點時要蓋住的字（功能、特徵、口訣解開、選擇題詳解都可以用）；`info`、`howto`、`heroLine`、`keyNote` 可放簡單 HTML，其餘欄位一律純文字。

用工具組 build 時，`build.py` 會先跑 `scripts/validate.py` 檢查這份規範：❌ 錯誤（網站會壞掉或違反規範）就不輸出網站；⚠️ 提醒（例如選項不是 4 個、正解詳解沒以「正確」開頭）照樣輸出，確認是故意的就可以留著。

### 最上層
```json
{"schema":"image-id-drill-site/1","site":{},"features":{},"labels":{},"info":[],"howto":[],"keyNote":"",
 "items":{},"groups":{},"chapters":[],"mnemonics":[],"cmp":[],"doubt":[],"quiz":{},"dims":{},"diagrams":{}}
```
**必填**：`site`、`features`、`labels`、`items`、`chapters`。其餘可省略（省略時當成空的）。

### site（網站設定）
| 欄位 | 說明 |
|---|---|
| pageTitle | **必填**。網頁名稱，例 `學校_病理實驗期中跑考_學期_作者_v1.0`，空著的項目省略 |
| h1 / topTitle | h1 **必填**，topTitle 可省（＝h1）。首頁大標、頂列短標題 |
| version | **必填**。例 `v1.0`，改版時和 pageTitle 一起改 |
| band | 可省。最多兩段文字的陣列，標籤帶左右兩段：`["學校・科目・系級・學期・by 作者","範圍"]`，空著的項目省略 |
| heroLine | 大標下一行說明，可用 `{items}`、`{groups}`、`{mn}`、`{diag}`、`{cmp}`、`{chapters}` |
| examDefault | **必填**。預設考試日 `YYYY-MM-DD` |
| storageKey / dbDoc | **必填**。存檔名稱（英數小寫加連字號，例 `school-patho-lab-mid-v1`、`progress`）。**發布後永遠不可改** |

### features（開工前問答的結果）
`{"atlas":true,"drill":true,"modes":["choice","flash"]}`
- `atlas` 與 `drill` 至少開一個；開 `drill` 時 `modes` 至少放一個。
- `atlas`：圖譜（各章卡片、只看圖、目錄、放大）。
- `drill`：跑考練習（含錯題本、收藏本、記憶曲線）。
- `modes`：作答模式，`choice` 選擇題、`flash` 單字卡；兩個都放時設定頁最上方出現切換，第一個是預設。兩種模式的作答紀錄、排程、錯題本分開（選擇題的紀錄 key 是 `C:`＋項目代號），收藏共用。

### labels（用詞）
`item`、`f`、`c`、`nameOrder` 必填（`nameOrder` 只能是 `en` 或 `zh`），其餘可省。
| 欄位 | 器械例 | 玻片例 |
|---|---|---|
| item | 器械 | 玻片 |
| f / c | 功能／特徵 | 看片重點／鑑別 |
| nameOrder | `en`（英文在前） | `zh`（中文在前） |
| question | 這是什麼器械？功能是什麼？ | 這張玻片的診斷是什麼？ |
| source | 器械講義 | 講義 |
| group / groupsTitle / groupsEn | 托盤／托盤擺設／Tray Set-Ups | （沒有組合圖可省略） |
| searchHint | 搜尋框提示 | |

### 首頁文字
- `info`：「網頁說明」每一條（可用上面的代換）。要寫範圍與依據、譯名說明、原圖數量、必考標記來源、哪些是自編與沒有老師審閱、遮標註的方式、進度存在哪裡。
- `howto`：「怎麼用」每一條。
- `keyNote`：必考頁上方的提醒（例如標記來源、沒標到的一樣可能考）。

### items（每一張圖＝一題）
```json
"appy":{"n":"Acute appendicitis","z":"急性闌尾炎","img":"s2_1m","orig":"s2_1","p":3,"pp":5,
 "f":["看片重點或功能，可用 ==關鍵字=="],"c":["特徵或鑑別"],"ef":"英文原文（可省略）","ec":"",
 "hw":"講義手寫（可省略）","warn":"留意（可省略）","must":"考肌層浸潤",
 "mc":{"o":["選項A","選項B","選項C","選項D"],"a":0,"e":["正確：…（頁碼）","…和這張圖的差別",…],"leak":false,"q":"題幹（洩題原題才需要）"}}
```
- `n`、`z`、`img`、`f`、`c`、`p` 必填；`f`、`c` 是陣列（一點一句）。
- 代號是作答紀錄的 key，發布後不可改。
- `img`：練習用的圖（玻片要遮掉標註）；`orig`：有標註的原圖（圖譜與答完後顯示）。沒有兩版時只寫 `img`。
- `p`：講義 PDF 頁碼；`pp`：印刷頁碼（可省略）。
- `must`：可省。教材明寫的必考標記，`true` 或一段說明（例如「考白色箭頭」）。有任何項目標了 `must` 時，跑考練習的「題數與順序」會多一排「全部／★ 只出必考」篩選，可以和出題順序一起用。
- `mc`：選擇題模式才需要（開了選擇題卻沒給的項目不會出題）。4 選 1（不是 4 個會出 ⚠️ 提醒），選項不可重複，`a` 是 0 起算的整數，`e` 數量＝選項數，正解位置分散。
  - 自編題目：題幹（`labels.question`、要另外寫 `q` 的題目、每章測驗 `quiz` 的 `q`）其餘用中文，但裡面的器官、構造、病名、器械名只寫英文、不加中文。
  - 自編題目：`o` 的四個選項**只寫英文專有名詞**（例如 `Clear cell renal cell carcinoma`），不加中文；干擾選項取同章、盡量同節或同部位的相關項目。`e` 的每一條都以「英文(中文)」開頭再接說明，正解那條寫「正確：英文(中文)。…（出處頁碼）」。
  - 洩題或考古原題：`leak:true`，`q` 放原題幹，`o` 的文字與順序完全照原樣（原本中英夾雜就照舊），`e` 一樣逐選項寫。

### chapters
`[{"id":"s2","t":"發炎","en":"Inflammation","pg":"p.3–5","plain":"白話說","items":["appy","gran"],"trays":[]}]`
`id`、`t` 必填，`id` 不可重複；`en`、`pg`、`plain` 也要寫（沒寫網頁會顯示 undefined）；`items`、`trays` 可省。每個項目都要放進、而且只能屬於一章。只有組合圖、沒有單項的章（例如托盤擺設）會成為獨立分頁。

### groups（組合圖，可省略）
`{"t_basic":{"n":"Basic Tray Set-Up","z":"基本托盤","img":"t_basic","p":19,"pp":36,"lp":19,"lpp":36,"note":"",
 "list":[[1,"英文名","中文名",0或1(螢光筆),"手寫字","對應的項目代號","通用拼法"],…]}}`；`n`、`z`、`img`、`list` 必填，清單每列剛好 7 欄，沒有對應項目時第 6 欄寫空字串

### 其他
- `mnemonics`：`[{"id":"mn1","ch":"s2","after":"項目代號","topic":"考點","mn":"口訣","ans":"解開（==關鍵字==）"}]`；`after` 可省，其餘必填，`id` 不可重複
- `cmp`：`[{"id":"cmp1","t":"標題","head":["項目","…"],"rows":[["項目代號","格",…]]}]`；每列第一格是存在的項目代號，格數＝表頭數
- `doubt`：講義疑誤 `[["位置","講義原文","說明","依據"]]`
- `quiz`：每章測驗（可省略）`{"s2":[{"s":"出處","q":"題幹","o":[…],"a":0,"e":[…],"img":"可省略"}]}`；除了 `img` 都必填，`img` 給的是圖片代號（要在 dims 裡）（每章測驗在網頁上整章標「自編」，不必逐題標記）
- `dims`：每張圖的寬高 `{"s2_1":[寬,高]}`（兩個數字），所有用到的圖都要有（「下載離線版」也靠它找出要打包的圖）
- `diagrams`：自繪示意圖 `{"d1":{"after":"項目代號","cmp":false,"html":"<figure class=\"card diag\">…</figure>"}}`；`html` 必填，`after` 要是存在的項目代號；`cmp:true` 也放進對照頁

### theme.css（風格）
只放 CSS 變數；淺色寫在 `:root{}`，深色寫兩次：`@media (prefers-color-scheme:dark){:root:not([data-theme="light"]){…}}` 與 `:root[data-theme="dark"]{…}`。
| 變數 | 用途 |
|---|---|
| --paper、--grid | 頁面底色、背景格線 |
| --surface、--surface2、--line | 卡片底、次要底、框線 |
| --ink、--muted | 主文字、次要文字 |
| --blue、--blue-soft、--on-blue | 連結、進度、選取色與其上的字色 |
| --main、--on-main | 主要按鈕與其上的字色 |
| --red/-soft、--green/-soft | 答錯與必考框、答對 |
| --hi、--hi-soft、--hi-ink、--on-hi | 螢光筆強調、標記、遮重點按鈕 |
| --tape、--mask、--photo | 紙膠帶、遮重點色塊、圖片底色 |
| --good、--bad | 答對、答錯文字 |
| --sans、--hand、--mono | 內文、標題、數字字型 |
