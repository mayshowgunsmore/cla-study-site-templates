【內容】
1. 一張圖一題，答案是名稱；器械、標本附功能與特徵，玻片附看片重點，每張都標講義頁碼。

4. 講義原圖上的文字標註與箭頭會洩答案：練習用的圖要遮掉（img），原圖另存（orig），答完與圖譜顯示原圖。抽幾張檢查沒有遮到組織。

5. 選擇題 4 選 1，正解位置分散；每個選項都寫詳解（正解寫「正確：」加圖上看得到的特徵與頁碼，其他寫和這張圖的差別）。

【組裝】
site.storageKey 與 site.dbDoc 取這個網站專用的名字，發布後永遠不要改。features 照我選的「要做哪些」與「作答模式」設定。寫好後用這段程式組成網站：

```python
import json,re
t=open('template.html',encoding='utf-8').read()
D=json.load(open('data.json',encoding='utf-8'))
data=json.dumps(D,ensure_ascii=False,separators=(',',':')).replace('</','<\\/').replace('<!--','\\u003c!--').replace('<script','\\u003cscript')
theme=open('theme.css',encoding='utf-8').read()
def put(pat,new):
    global t; t,n=re.subn(pat,lambda m:new,t,count=1,flags=re.S); assert n==1,pat
put(r'(?<=<script id="site-data" type="application/json">).*?(?=</script>)',data)
put(r'(?<=<style id="theme">).*?(?=</style>)','\n'+theme+'\n')
put(r'(?<=<title>).*?(?=</title>)',D['site']['pageTitle'])
open('index.html','w',encoding='utf-8').write(t)
```

發布時把 index.html 和 fig/ 一起放上去（在 Claude 發布時，要開啟儲存進度的 db、user，以及「下載網站模板」「下載離線版」用的 downloads 權限）。首頁的「下載離線版」會把網站和 dims 列到的全部圖片打包成一個 HTML 檔，斷網也能用，模板已內建，不用另外做，所以每張用到的圖都要列在 dims。要 A4 PDF 時另外做一份列印版：每個編號盡量同一頁、圖多的一排三張、沒有跨頁與空白頁。
