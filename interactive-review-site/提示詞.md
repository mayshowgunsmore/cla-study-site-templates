# 互動式複習網站（通用版提示詞）

請用我附上的 **template.html**（複習網站「網頁提示詞」裡按「下載網站模板」取得）加上我的教材（今年上課講義、共筆等）與題庫，做出同一套互動式複習網站，只是換成我的科目。全站用台灣繁體中文，英文專有名詞後面加（中文）；測驗的題幹與選項例外（見「本節測驗」）。請在可以執行程式、上傳檔案的環境使用。

**做法：模板已經包含全部功能與版面，不要重寫或修改模板程式。** 你只要準備：
- `data.json`：這一科的內容與設定，格式照最下方「data.json 規範」。
- `theme.css`：配色風格，只放 CSS 變數。
- `fig/` 資料夾：從教材裁切的原圖（JPEG）。

再用程式把 data.json 與 theme.css 填進模板，輸出成網站，連同 fig/ 一起發布。

## 開始前一次問完
1. **科目與考試**：科目名稱、考試名稱與日期、考試範圍對應哪些檔案。
2. **資料**：請我上傳今年上課講義、共筆，以及題庫或考古題（有的話）。我附的每一份都是有效來源，**主要依據預設是今年上課講義**，共筆與其他資料補充；內容不一致時以主要依據為準並標出另一邊的說法。我也可能直接在對話裡口述補充或指定重點，那也算來源。沒有 template.html 或沒有教材，就先跟我要，不要自己編內容。
3. **風格**：請我用文字描述想要的感覺（例如簡潔清爽、柔和粉彩、沉穩專業），或給顏色碼、參考網站；先整理成配色摘要（主色、強調色、背景、主要按鈕色、深色模式）給我確認再開工。
4. **標題區**：學校、系級、學期、作者署名；不想寫的留空，網站上就不顯示。
5. **版本號**：沒指定就用 v1.0。

## 內容原則
1. 讀完範圍內每一份資料（講義、共筆、老師補充檔），包含圖片裡的文字、螢光筆與手寫註記（PDF 抽字抽不到的要把頁面轉成圖片看過）。依章節整理成好掃讀的重點與表格，每節標出 PDF 頁碼（用程式搜尋標題算實際頁碼，不用頁尾數字）。
2. 抽查各份資料之間的差異。不一致處不要直接改掉，保留主要依據的寫法，用提示框附上另一份的說法和頁碼，也列進不一致清單；是自己推論的要講明。
3. 主要依據以外、但其他資料或考古題考過的內容可以放，要標示來源，不可混進主要依據的內容裡。

## 讓內容好懂
- **白話說**：每節開頭 2～5 句白話說明，不超出提供的資料，可用比喻。
- **中文註解**：把用到的英文專有名詞與中文譯名整理成 `gloss`，網頁會自動加註。
- **口訣**：要背的考點都設計口訣，放在該段內文旁；每則有考點、口訣、解開，標明是自編。
- **示意圖**：重要但沒有好原圖的敘述，自己畫 SVG 示意圖，註明非實際比例，答案文字可被遮住，不要為了數量硬做。圖上的數字與敘述都要是資料裡有寫的。
- **互動圖**：挑最需要空間想像、分類、步驟或數字比較的主題，做成點按鈕或點圖會換說明的 SVG。

## 教材原圖
**優先用今年講義的圖**，講義沒有或畫質太差才用共筆或其他資料的圖。把資料裡的圖片與圖片形式的表格取出來：**能用原始圖檔就用原始圖檔**（PDF 用 PyMuPDF 取內嵌圖、docx 用 `pandoc --extract-media`），畫質最好也不會截歪；每頁都出現的背景、校徽略過。圖上另外疊了標註、箭頭、引線，或一張圖由好幾塊拼成時，原始圖檔缺了這些，改用 PyMuPDF 依圖在頁面上的位置（連同貼著它的標註一起框進來）以原圖解析度、至少 200 dpi 渲染那一區；掃描檔與向量繪圖也這樣渲染裁切。最後一律存成寬度上限 1300px、JPEG 品質 80，穿插在它所說明的段落旁，不要集中在節末。每張附自己寫的圖說，頁碼要註明是哪一份資料（例 `講義 L03 p.12`），完成後做一張總覽圖逐張核對位置與圖說。

## 必考篩選
**我附的每一份資料都可以有標記**，不要只找共筆：講義或共筆的文字標記（必考、必背、很重要、重要、國考、老師提到、可先略過）、講義上的螢光筆或手寫註記、老師上課說的、以及我在對話裡直接口述指定的，都算明寫的標記，要自己判斷並註明出處（我口述的就寫「使用者指定」）。引用原文並附是哪一份資料的第幾頁。不可把你自己判斷的重點標成必考；標可略過但考古題考過的，要註明不建議略過。某一份資料幾乎沒有標記時要提醒別因此跳過。

- **高頻必考（內建）**：除了資料明寫的必考標記，另外依考古題重複出現的次數標「高頻必考」：同一考點（正解相同）出現在 3 份以上考卷（含國考）的，該節 `tags` 加 `freq`，並在 `key` 加一筆 `t:"freq"`（`q` 寫考點、`p` 列出所有考卷）。這是依頻率判定，不是老師說的，和明寫的必考分開標、可以並存；門檻不同時改 `labels.freqTip` 說明。
- **自訂標籤**：某一科需要另一種篩選（例如實驗課跑考、口試、臨床相關）時，用 `tagDefs` 定義標籤名稱並開篩選鈕，在相關的節 `tags` 加上代號，不要改模板。必考標記頁需要新分類時（例如換老師後的「講義重點」，或考古題常考、但今年講義沒教到而降級的「舊課考點」），一樣在 `tagDefs` 定義（可給 `tone`、`tip`、`plain`），`key` 的 `t` 寫這個代號。

## 本節測驗
每節後面放小測驗，目的是幫助記住該節的知識點。先列出該節要記的知識點（必考與考古題考過的優先），題數依知識點多寡決定，通常 3～8 題：每個重要知識點至少一題，同一個知識點不重複出題。題目先從我提供的考題挑（答案與詳解沿用來源），題庫沒涵蓋到的重要知識點再依提供的資料自編，題庫題與自編題的比例由你判斷。
- 模板已內建**錯題本**（答錯自動收進來）與**複習卡收藏**（每一節是一張複習卡，節標題右邊的「☆」收進來，收藏頁顯示整節內容）；題目本身不另做收藏，也不做記憶曲線。
- **題庫題的題幹與選項完全照原文**：不改寫、不翻譯、不加也不刪中文、不換選項順序。只有合併重複題（採最舊那卷的原文）與原文缺漏時可以動；缺漏先用同一題的其他卷別補，沒有再依資料補，補上的字用〔 〕括起來，在 `doubt` 寫明補了什麼、依據哪份資料第幾頁。
- **自編題的專有名詞只寫英文**：題幹與選項裡的藥名、受體、構造、病名等一律只寫英文、不加中文，題幹其餘用中文；中文只放在答完後的詳解，寫成「英文(中文)」。模板不會在題幹與選項加註，不要改模板。
- 自編題標「自編」並寫明依據的資料名稱與頁碼，正解位置分散，不出資料裡沒寫的內容。要看圖但沒有圖的題目、多選題、和網站內容互相矛盾的題目先略過，記進 `doubt`。

## 組裝
`site.storageKey` 與 `site.dbDoc` 取這個網站專用的名字（英數小寫加連字號），發布後永遠不要改，否則大家的進度會接不上。寫好後用這段程式組成網站：

```python
import json,re
t=open('template.html',encoding='utf-8').read()
D=json.load(open('data.json',encoding='utf-8'))
data=json.dumps(D,ensure_ascii=False,separators=(',',':')).replace('</','<\\/').replace('<!--','\\u003c!--').replace('<script','\\u003cscript')
theme=open('theme.css',encoding='utf-8').read()
def put(pat,new):
    global t; t,n=re.subn(pat,lambda m:new,t,count=1,flags=re.S); assert n==1,pat
put(r'(?<=<script id="site-data" type="application/json">).*?(?=</script>)',data)
put(r'(?<=<style id="theme">).*?(?=</style>)','\n'+theme+'\n')
put(r'(?<=<title>).*?(?=</title>)',D['site']['pageTitle'])
open('index.html','w',encoding='utf-8').write(t)
```

發布時把 index.html 和 fig/ 一起放上去（在 Claude 發布時，要開啟儲存進度的 db、user，以及「下載網站模板」「下載離線版」用的 downloads 權限）。首頁的「下載離線版」會把網站和 figCaptions 列到的全部原圖打包成一個 HTML 檔，斷網也能用，模板已內建，不用另外做，所以每張原圖都要列在 figCaptions。首頁的「進度備份」可以把作答紀錄、收藏與考試日期下載成一個 .json 檔，上傳時選「合併」或「取代」（可復原，別的網站的進度檔會被拒收），用來換裝置或在線上版與離線版之間搬進度，同樣是模板內建、用同一個 downloads 權限，不用另外做。

## 完成前檢查
1. 用程式檢查 data.json：節 id 不重複、每個穿插錨點在該節剛好出現一次、每張原圖都放到且只放一次、口訣與示意圖代號不重複、每節測驗 3～8 題、答案在選項內、詳解數等於選項數。
2. 用手機、平板、寬螢幕尺寸實際操作：互動圖、每一題測驗、複習卡收藏與取消收藏（節標題的☆按下不會開合該節）、錯題本與複習卡收藏頁、標記完成（要答完才能按）、底部分頁、修改倒數日期、篩選、原圖放大、遮重點和搜尋、進度備份的下載與上傳（合併、取代、復原），確認都有反應、圖片載得出來、沒有錯誤訊息、沒有左右捲動，淺色與深色模式都好讀。
3. 之後要修改時只改 data.json、theme.css 或圖片再重新組裝，並先問我新的版本號。
4. 回報：最後附一張**編號的「待你確認」清單**（每條寫遇到什麼、你怎麼處理、要改會變成怎樣），我才能直接回第幾項要改；另外列資料不一致清單、哪些內容不在主要依據內（註明來源）、必考標記各自來自哪一份資料、題庫題與自編題各有多少、哪些是自編內容（白話說、譯名、口訣、示意圖），以及測試過和沒測到的部分。

## data.json 規範（interactive-review-site/1）

網站＝模板（固定程式與版面）＋ data.json（這一科的內容）＋ theme.css（風格）＋ fig/ 資料夾（共筆原圖，檔名＝原圖代號.jpg）。只寫 data.json、theme.css 與圖片，不改模板。全站台灣繁體中文。

文字欄位的格式：
- **HTML**：可用一般標籤（`<ul> <ol> <li> <p> <h4> <b> <table>`、`<div class="tw">` 包表格、`<div class="note fix|tip|teach"><b>標題</b>內容</div>` 提示框）。
- **==關鍵字==**：遮重點時會蓋住的字，可用在內文、口訣解開、互動圖說明。
- 一般文字欄位（標題、出處、圖說）不要放 HTML。

用工具組 build 時，`build.py` 會先跑 `scripts/validate.py` 檢查這份規範：❌ 錯誤（網站會壞掉或違反規範）就不輸出網站；⚠️ 提醒（例如測驗題數不在 3～8、正解詳解沒以「正確」開頭）照樣輸出，確認是故意的就可以留著。

### 最上層
```json
{"schema":"interactive-review-site/1","site":{},"labels":{},"tagDefs":{},"info":[],"howto":[],"keyTip":"","sprint":{},"css":"",
 "chapters":[],"figSize":{},"figCaptions":{},"mnemonics":{},"diagrams":{},"widgets":{},"place":{},
 "key":[],"fix":[],"extra":[],"hot":[],"doubt":[],"cmp":[],"num":[],"gloss":{},"quiz":{},
 "features":{},"favNote":"","wrongNote":"","verdictPatterns":[]}
```
**必填**：`site`、`chapters`。其餘可省略（省略時當成空的）。

### site（網站設定）
| 欄位 | 說明 |
|---|---|
| pageTitle | **必填**。網頁名稱（分頁與 Artifact 標題），例 `學校_科目期末複習_學期_作者_v1.0` |
| name / version | **必填**。首頁小字的網站名稱與版本，例 `學校_科目期末複習_學期_作者`、`v1.0` |
| title / sub | **必填**。左側目錄頂端的短標題與小字，例 `病理 期末複習`、`1151 ・ 作者 ・ v1.0` |
| h1 | **必填**。首頁大標，例 `病理學期末複習` |
| heroLine | 接在網站名稱後的一行說明（可空），例 `　1151 學年・醫學系　範圍：共筆 n01–n08` |
| examName / examDefault | **必填**。考試名稱與預設日期 `YYYY-MM-DD`，倒數用 |
| storageKey / dbDoc | **必填**。存檔名稱（英數小寫加連字號，例 `school-patho-fin`、`progress`）。**發布後永遠不可改**，否則進度會不見 |
| contentVersion | 可選。**內容大改版、節的切法變動時才換一個新值**（例 `2026-11-15`）。值一變，使用者下次開啟會做一次性進度搬移：有 `secMap` 就只保留 map 裡對應得到的節，沒有就只保留仍存在的節 id；題目集合會變所以測驗與錯題一律清掉，考試倒數日期保留。本機與雲端兩條路徑都會搬。沒設這個欄位的網站完全不受影響 |
| secMap | 可選，搭配 `contentVersion` 用：`{"舊節 id":"新節 id"}`。節重新切分或改代號時給它，進度才對得上；沒給就只留仍存在的節 id |
| chapterHeading / foot | 首頁章節區標題、頁尾小字（可放版權提醒） |
| tabs | 可選。底部分頁與順序，只能用 `home`、`key`、`sprint`、`cmp`、`num`、`mn`、`wrong`、`fav`；沒給就是這八個全開（沒有內容的自動隱藏） |

**改到既有的測驗題時不必動 `contentVersion`**：作答存成「節 id#題號」，但模板會一併存題幹＋選項的指紋，下次開啟比對不符就只丟掉那一題的作答與錯題。所以在節中間插題、調換題序、改寫題目都不會讓使用者看到別題的舊答案，不必刻意只往後加題；題目沒動的作答完全保留。

### labels（教材來源字樣，可省略）
模板預設把教材統稱「教材」。主要依據是共筆、講義或其他教材時，用這裡改成實際的名稱，整站說明才會正確。沒給就用預設。

| 欄位 | 預設 | 說明 |
|---|---|---|
| must | `教材標必考` | 章節頁「必考」篩選鈕與必考標籤的字 |
| keySub | `只收教材明寫的字樣，引用原文並附頁碼；不含本站自行判斷的重點` | 必考標記頁副標 |
| sprintSub | `考古題重複出現的考點、教材疑誤、教材以外但考過的內容` | 考前衝刺頁副標 |
| mnSub | `全部為本站自編，不是教材或老師提供；開啟遮重點可以蓋住解答來默背` | 口訣總表頁副標 |
| freq | `高頻必考` | 內建「高頻必考」標籤、章節頁篩選鈕與必考標記頁分類的字 |
| freqTip | `依考古題重複出現的次數判定（同一考點出現在 3 份以上考卷），只代表常考，不等於教材或老師標的必考。` | 必考標記頁「高頻必考」的判定說明；判定門檻不同時要改 |

疑誤表自己的標題與表頭另外用 `sprint.fixTitle`、`sprint.fixHead`、`sprint.extraTitle` 改。

例：以共筆為主 → `{"must":"共筆標必考","keySub":"只收共筆明寫的字樣…"}`。依考古題頻率判定的重點不要塞進 `must`，改用內建的 `freq`（見下方 tags 與 key），兩種標記可以並存。

### 首頁文字
- `info`：「網頁說明」段落 `[{"h":"範圍","t":"HTML"}]`。可用代換：`{chapters}` 份數、`{secs}` 節數、`{figs}` 原圖、`{keys}` 必考標記、`{quizSecs}` 有測驗的節、`{qTotal}` 題數、`{qSelf}` 自編題、`{gloss}` 註解、`{mn}` 口訣、`{diag}` 示意圖、`{wg}` 互動圖。
- `howto`：「怎麼用」每一條（HTML），可用 `{examDefaultMD}`（預設考試日 M/D）。
- `keyTip`：必考頁「全部／可先略過」時顯示的提示框 HTML，可空。
- `sprint`：`{"hotTitle":"重複考點標題（預設「考古題重複出現的考點」）","hotLead":"考過的考點來源說明","fixLead":"教材疑誤的說明","fixTitle":"疑誤表標題（預設「教材疑誤」）","fixHead":["教材寫法","對照","怎麼記"],"extraTitle":"教材以外、但考古題考過的內容","doubtTitle":"doubt 清單標題（預設「沒有收進測驗、或答案要再確認的考古題」）"}`，每個都可省；`fixHead` 要剛好三格。
- `favNote`、`wrongNote`：收藏頁、錯題本頁標題下的說明文字（純文字），可省，沒給用模板預設。
- `css`：這一科專用的 CSS，例如示意圖的組織色 token（淺色、深色各一組），可空。

### chapters（各份共筆）
```json
{"id":"n01","no":"n01","t":"細胞損傷","en":"Cell Injury","teacher":"老師","date":"9/10","pdf":"共筆 n01（20 頁）","note":"",
 "secs":[{"id":"n01-1","t":"節標題","src":"n01 p.1–5","tags":["must","past"],"plain":"白話說 2～5 句","html":"<ul><li>…==關鍵字==…</li></ul>"}]}
```
- 章節的 `id`、`no`、`t`、`secs` 必填，節的 `id`、`t`、`src`、`html` 必填；`plain`、`tags` 可省。
- 節 `id` 是進度存檔的 key，發布後不可改。`tags`：`must` 教材標必考、`freq` 高頻必考（考古題重複出現，預設門檻 3 份以上考卷）、`past` 考過、`nat` 國考、`imp` 很重要。任一節標了 `freq`，章節頁就多一顆「高頻必考」篩選鈕；沒用到時不出現。
- `note`：這一章要注意的事（紅色提示框），可空。

### tagDefs（自訂節標籤，可省略）
`{"run":{"name":"跑考","filter":true}}`（`name` 必填；代號不可和內建標籤 `must`、`freq`、`past`、`nat`、`imp`、`teach`、`skip` 重複）：除了內建的 `must`、`freq`、`past`、`nat`、`imp`，還可以自訂標籤代號（英數小寫），節的 `tags` 裡寫這個代號就會顯示 `name` 的字。`filter:true` 時章節頁的篩選鈕會多一顆，只留有這個標籤的節。標籤顏色可直接給 `tone`（`blue`、`green`、`red`、`gold`、`gray`，跟著配色自動適應淺色與深色），要更細的樣式再用 `css` 寫 `.chip.代號{…}`；配套的提示框可用 `<div class="note 代號">`，同樣在 `css` 定義樣式。例：實驗課跑考、口試、臨床相關。

**自訂必考標記**：`key` 的 `t` 也可以寫 tagDefs 的代號，必考標記頁就自動多一個以 `name` 命名的分類（排在「高頻必考」後面）。可另給 `tip`（該分類的判定說明，選到這個分類或「全部」時顯示）與 `plain:true`（卡片文字不加引號，用在不是引用原文、而是本站整理的標記）。例：
`{"lec":{"name":"講義重點","tone":"blue","plain":true,"tip":"今年講義用整頁、整張表或投影片標題在講的內容…"},"old":{"name":"舊課考點","tone":"gray","plain":true,"tip":"考古題常考、但今年講義沒教到的考點…"}}`

### 原圖
- `figCaptions`：`{"n01-p3-1":["圖說（自己依圖與前後文寫）","n01 p.3"]}`，代號＝檔名，圖片放 `fig/n01-p3-1.jpg`。每張原圖都要列在這裡，「下載離線版」靠它找出要打包的圖。
- `figSize`：`{"n01-p3-1":["n01-p3-1",寬,高]}`，用來預留空間；每張原圖都要有。

### 口訣、示意圖、互動圖
- `mnemonics`：`{"m1":{"sec":"n01-1","p":"考點","m":"口訣本身","e":"解開（==關鍵字==）"}}`
- `diagrams`：`{"d1":{"sec":"n01-2","cap":"圖說（自繪示意圖，非實際比例）","svg":"<svg class=\"fig\" viewBox=\"0 0 440 200\">…</svg>"}}`；答案文字加 `class="lbl"`，遮重點時會蓋住。顏色用 theme 或 `css` 裡的 token。
- `widgets`：`{"w1":{"sec":"n01-3","t":"標題","svg":"<svg class=\"fig\" …>…<circle class=\"pt\" data-k=\"a\" …/>…</svg>","opts":[["a","按鈕文字","說明 HTML"],…]}}`；圖上可點的元素加 `class="pt" data-k="代號"`，和 opts 的代號對應；`opts` 每一項剛好三格 `[代號,按鈕文字,說明 HTML]`，至少一項。
- 代號（原圖、口訣、示意圖、互動圖）全站不可重複。

### place（穿插位置）
`{"n01-1":[["錨點文字","n01-p3-1"],["錨點文字","m1"],["@end","d1"]]}`：項目插在該節 html 裡錨點文字所在的那段（`</li>`、`</p>` 等）後面；`@end` 放節末；項目寫 `@skip` 表示這一列先不放（暫時保留）。錨點要在該節剛好出現一次；同一段要放好幾個項目時沿用同一個錨點。每張原圖都要放到且只放一次。

### 必考、衝刺、對照、數字
- `key`、`fix`、`extra`、`hot` 的 **`sec` 必填**，而且要是存在的節 id（網頁靠它顯示章節編號，少了會整頁壞掉）；`num` 的 `sec` 可省（給了就能點一列跳到該節）。下面列出的其他欄位都必填。
- `key`：`[{"t":"must|imp|nat|teach|skip|freq|tagDefs 代號","sec":"n01-2","q":"引用共筆原文","p":"n01 p.4"}]`
  - `t:"freq"`（高頻必考）：`q` 寫考點（可寫成「題幹　答：正解」），`p` 寫出現過的考卷（例 `1141-16、1132-15、1122-15（3 卷）`）。有 `freq` 項目時，必考標記頁多一個「高頻必考」分類並顯示 `labels.freqTip`；這類卡片不加引號，因為不是引用原文。
- `fix`（共筆疑誤）：`[{"sec","t":"項目","n":"共筆寫法","h":"對照（講義頁碼）","r":"怎麼記"}]`
- `extra`（共筆以外但考過）：`[{"sec","t","s":"來源","d":"內容"}]`
- `hot`（考古題重複考點）：`[{"sec","t","n":"出處"}]`
- `doubt`：沒收進測驗或答案待確認的題目說明（文字陣列，每筆一段純文字）
- `cmp`（易混淆對照）：`[{"g":"分組","t":"標題","h":["表頭",…],"rows":[["格",…],…]}]`，每列格數＝表頭數，格內可用簡單 HTML
- `num`（數字速查）：`[{"g":"分組","v":"數字","d":"是什麼","sec":"n01-1"}]`

### features（功能開關）
`{"wrong":true,"fav":true,"quizSource":"section"}`，都可省略；`wrong`、`fav` 預設開啟。`quizSource` 決定測驗詳解下方「出處」顯示什麼：`section`（預設）顯示該節的 `src`，`question` 改顯示每題自己的 `s`（題庫題來自不同考卷時用）。`wrong` 錯題本：答錯的題目自動收進來，只在網站有測驗時出現；`fav` 複習卡收藏：每一節就是一張複習卡，節標題右邊的「☆」（或節末「☆ 收藏這張卡」）收進來，收藏頁照章分組顯示整節內容（含原圖、跑考卡、測驗），可依章篩選、搜尋。題目本身不另做收藏。兩者都跟著帳號同步（複習卡收藏沿用存檔的 star 欄位，舊網站的「待複習」標記會直接變成收藏）。`site.tabs` 沒給時底部分頁預設是首頁、必考、衝刺、對照、數字、口訣、錯題、收藏（沒有內容的自動隱藏）；有自訂 `site.tabs` 時要把 `wrong`、`fav` 放進去才會出現在底部分頁（左側目錄一律有）。

### gloss（中文註解）
`{"biofilm":"生物膜"}`：英文專有名詞 → 中文，網頁會自動在英文後面加（中文），同一節只註第一次。

### quiz（本節測驗）
`{"n01-1":[{"s":"出處","q":"題幹","o":["選項",…],"a":0,"e":["正確答案。…","錯。…",…],"k":"重點","t":"易錯（可省略）","self":false}]}`
- 每節題數依知識點多寡，通常 3～8 題（每個重要知識點至少一題，不重複考同一點）；`a` 是 0 起算的正解索引；`e` 與 `o` 數量相同，正解那項以「正確」開頭。
- 自編題 `self:true`，`s` 寫依據的共筆頁碼；正解位置要分散。題幹與選項的專有名詞只寫英文、不加中文，`e` 裡第一次出現時寫成「英文(中文)」。
- 題庫題的 `q`、`o` 照原文，不改寫、不翻譯；模板不會在題幹與選項加中文註解。
- `s`、`q`、`o`、`a`、`e`、`k` 必填，至少 2 個選項；`a` 是整數。

### verdictPatterns（詳解判定語，可省略）
詳解開頭的判定語（例「正確答案。」「錯。」）會被抽出來變成小標籤，避免和內文重複。預設 `[["^正確答案。\\s*","正解"],["^對的敘述。\\s*","正確敘述"],["^錯。\\s*","錯"]]`。這一科的詳解用別的寫法時，自己列：每筆 `["正規表示式","標籤"]`，標籤可用 `$1` 帶入括號內的字，寫 `null` 表示只刪掉判定語、不顯示標籤；依序比對，第一個符合的生效。有給 `verdictPatterns` 時，正解詳解就不必以「正確」開頭。

### theme.css（風格）
只放 CSS 變數；淺色寫在 `:root{}`，深色寫兩次：`@media (prefers-color-scheme:dark){:root:not([data-theme="light"]){…}}` 與 `:root[data-theme="dark"]{…}`。
| 變數 | 用途 |
|---|---|
| --paper、--grid | 頁面底色、背景格線 |
| --surface、--surface2、--line | 卡片底、次要底、框線 |
| --ink、--muted | 主文字、次要文字 |
| --blue、--blue-soft | 連結、測驗、互動圖、關鍵字顏色 |
| --main、--on-main | 主要按鈕底色與字色 |
| --red/-soft、--green/-soft | 章節編號與疑誤框、白話與完成 |
| --hi、--hi-soft、--hi-ink | 螢光筆強調、口訣框、遮重點按鈕 |
| --tape、--mask | 卡片紙膠帶、遮重點色塊 |
| --good、--bad | 答對、答錯 |
| --sans、--hand、--mono | 內文、標題與口訣、數字字型 |
